# Classification capacity experiments

Each dated folder here is isolated from the production classification workflow. Experiment packets may combine multiple 100-title hydration batches to measure model context capacity, output completeness, schema validity, and classification quality.

Hydrated title evidence is reusable, but experiment classifications must not be published to Supabase unless an explicit evaluation promotes them into a production batch artifact.

Dated experiment directories are ignored by Git. Keep the reusable workflow in source control and archive run packets outside the repository when an audit trail is required.
